# Axiom Synthesis Engine
A statistical engine for experimentation problems.

## The Anatomy of the Name
* **Axiom:** Represents the Test Planning and SRM components. It tells the client that the foundation of the test is statistically sound and the starting point is a "self-evident truth."
* **Synthesis:** Represents the Interaction, Compound Growth, and Frequentist/Bayesian hybrid approach. It shows that the engine "assembles" these complex algorithms into one clear, actionable direction.
* **Engine:** Communicates Automation and Scale. It’s not a manual spreadsheet; it’s a high-performance machine running in the background.
